# 🎬 MovieSafari

A Netflix-inspired movie browsing website built with pure HTML, CSS, and JavaScript. MovieSafari features a clean, modern UI with smooth interactions, dark/light mode toggle, and a responsive layout.

## 🚀 Live Demo

>  https://moviesafari-manav.netlify.app/

## 📸 Screenshots
![MovieSafari Screenshot](screenshot.png)

## ✨ Features

- 🎥 **Movie Listings** — Browse movies across multiple categories (New Releases, Trending, etc.)
- 🌙 **Dark / Light Mode** — Toggle between dark and light themes seamlessly
- ➡️ **Horizontal Scrolling** — Smooth arrow-based scrolling through movie cards
- 🎞️ **Featured Banner** — Hero section highlighting featured movies with Watch button
- 📱 **Responsive Design** — Works across different screen sizes
- 🧭 **Sidebar Navigation** — Icon-based sidebar for quick navigation
- 👤 **Profile Section** — Profile area in the navbar

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Structure and layout |
| CSS3 | Styling, animations, dark/light mode |
| JavaScript (Vanilla) | DOM manipulation, toggle, scroll logic |
| Font Awesome | Icons throughout the UI |

## 📁 Project Structure

```
MovieSafari/
├── index.html        # Main HTML file
├── style.css         # All styling including dark/light mode
├── b.js              # JavaScript for scroll and toggle functionality
├── img/              # All movie poster and banner images
└── README.md         # Project documentation
```

## ⚙️ How to Run Locally

1. Clone the repository
```bash
git clone https://github.com/manav40487-netizen/MovieSafari.git
```

2. Navigate to the project folder
```bash
cd MovieSafari
```

3. Open `index.html` in your browser — no installation needed!

## 💡 Key JavaScript Concepts Used

- **DOM Manipulation** — dynamically selecting and modifying elements
- **Event Listeners** — handling click events for scroll arrows and toggle
- **CSS Transform** — smooth horizontal scroll using `translateX`
- **classList.toggle** — switching between dark and light mode classes
- **querySelectorAll** — selecting multiple elements efficiently
